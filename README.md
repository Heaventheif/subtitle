# خادم الترجمات v3 — Go (فائق السرعة)

خادم وسيط للترجمات بلغة **Go**، مُعاد بناؤه بالكامل من أجل **السرعة القصوى**:

- **بلا ذكاء اصطناعي وبلا ترجمة آلية** — أُزيل النظام نهائياً (كان يضيف 10–60 ثانية لكل بحث).
- **بلا TMDB/Wyzie/YIFY/Firecrawl** — فقط مزوّدا API مباشران: **OpenSubtitles + SubDL**.
- **بروتوكول v2** نفسه المتوافق مع التطبيق (البصمة أولاً، حقول `hash_match` و`fps` و`slangs`).

## لماذا هذا سريع؟

| التصميم | الأثر |
|---|---|
| Go خام على `net/http` — بلا framework، binary ثابت واحد | إقلاع < 1 ثانية، بلا pip/npm |
| المزوّدات الثلاث (بصمة OS + اسم OS + SubDL) **بالتوازي** | زمن البحث = أبطأ مزوّد فقط |
| مهلة صارمة `SEARCH_TIMEOUT_MS` (افتراضي 6 ثوانٍ) | الرد الجزئي أفضل من الرد البطيء |
| كاش ثلاثي الطبقات: ذاكرة ساخنة (نحو 24µs لكل طلب) → bbolt mmap → الشبكة | النتائج المتكررة فورية |
| singleflight | الطلبات المتطابقة المتزامنة تنتظر ريقاً واحداً |
| كاش سلبي للنتائج الفارغة (3 ساعات) | الفيلم بلا ترجمة لا يضرب المزوّدين مراراً |
| إعادة استخدام اتصالات TLS (HTTP/2) | يوفر 100–300ms في كل طلب لاحق |
| تدوير المفاتيح مع توقف تلقائي عند 429/401 | لا انتظار ولا فشل عند استنفاد مفتاح |
| النبض الذاتي (`KEEP_ALIVE_URL`) | يمنع نوم Render المجاني واستيقاظه البارد (~60 ثانية) |

قياسات فعلية (Xeon، مزوّدون وهميون بزمن 150ms):
`BenchmarkSearchCached` = **24µs/طلب** · `BenchmarkSearchUpstream` = **151ms** (فوقية ~1ms فقط).
الثنائي الناتج: ~7.5MB، تشغيل بلا أي اعتماد خارجي.

## البروتوكول (v2 — مطابق لملف README الخاص بالتطبيق)

```
GET /search?lang=ar,en&v=2&filename=...&hash=8e245d9679d31e12&size=...
    &dur=...&w=...&h=...&fps=23.976&vcodec=h264&alangs=en&slangs=en&q=
X-App-Token: <الرمز>
```

الترتيب داخل الخادم:
1. تحقق الرمز (`401`) ثم حد المعدل (`429`).
2. قراءة الحقول وتجاهل المجهول (متوافق مع التطبيقات القديمة التي ترسل `imdb_id`/`season`…).
3. **البحث بالبصمة أولاً**: كل نتيجة تطابق البصمة تأخذ `hash_match: true` و`match: 100` وتُرتَّب أولاً (`tier: 1`).
4. البحث بالاسم: استخراج العنوان/السنة/الموسم/الحلقة من `filename` (أو `q`) وترتيب النتائج بتطابق الإصدار والسنة والحلقة و`fps` والتحميلات.
5. `slangs`: اللغات المضمّنة أصلاً تُستبعد من النتائج (حسب v2).
6. الكاش: المفتاح = البصمة إن وُجدت وإلا `filename+q+lang` (+slangs).

الرد:

```json
{
  "query":  { "title": "Movie Name", "year": 2021, "season": null, "episode": null },
  "tier": 1,
  "cached": false,
  "results": [
    { "id": "3f2a9c1e77b04d12", "source": "opensubtitles", "lang": "ar",
      "release": "Movie.Name.2021.1080p.BluRay.x264", "match": 100,
      "hash_match": true, "rating": 8.5, "downloads": 12034,
      "format": "srt", "hi": false, "fps": 23.976 }
  ]
}
```

الأخطاء: `401` الرمز خاطئ · `429` طلبات كثيرة · `503` انتهت حصة التنزيل/لا مفاتيح · `400` بلا filename/q · غير ذلك خطأ خادم.

### تنزيل الترجمة

```
GET /file/{id}              (نفس ترويسة X-App-Token)
← 200 جسم الاستجابة = ملف الترجمة (UTF-8 دائماً)
     X-Subtitle-Format: srt
     X-Subtitle-Lang:   ar
```

يُفك الأرشيف (ZIP) ويُصلح الترميز (Windows-1256/ISO-8859-6/UTF-16 → UTF-8) عبر جداول مولّدة مسبقاً — بلا مكتبات ترميز خارجية، ويُخزَّن الملف الناتج ليعاد فوراً في الطلبات اللاحقة.

### الصحة

`GET /health` (بلا رمز): حالة المزوّدات والكاش والنبض الذاتي.

## التشغيل المحلي

```bash
go build -o subtitle-server .
cp .env.example .env    # املأ المفاتيح ثم صدّرها كمتغيرات بيئة
./subtitle-server       # PORT=8000 افتراضياً

go test ./...           # اختبارات كاملة بمزوّدين وهميين (بلا شبكة)
go test -bench=. -benchmem -run=^$   # قياسات الأداء
```

## النشر على Render

New → Blueprint (يقرأ `render.yaml`). أضف من لوحة Render:
- `OPENSUBTITLES_ACCOUNTS` قائمة JSON للحسابات
- `SUBDL_API_KEYS` مفاتيح SubDL
- `APP_TOKEN` يُولَّد تلقائياً — ضعه في التطبيق (الإعدادات ← الترجمات الإلكترونية)

تنبيهات الخطة المجانية:
- القرص مؤقت: يُفقد الكاش عند إعادة التشغيل (للثبات اربط قرصاً دائماً وضع `DB_PATH` عليه).
- العدّادات اليومية للمفاتيح في الذاكرة وتُصفَّر عند إعادة التشغيل.
- النبض الذاتي يقرأ `RENDER_EXTERNAL_URL` تلقائياً ويستدعي `/health` كل 10 دقائق؛ الأوثق إضافة مراقب خارجي (UptimeRobot أو cron-job.org).

## بنية الكود

| الملف | الدور |
|---|---|
| `main.go` | الإقلاع والإيقاف السلس (SIGTERM) |
| `config.go` | الإعدادات من متغيرات البيئة |
| `server.go` | التوجيه، المصادقة، حد المعدل، singleflight، `/search` و`/file/{id}` |
| `parser.go` | استخراج العنوان/السنة/الموسم/الحلقة ووسوم الإصدار (بدون lookaround — RE2) |
| `ranking.go` | الترتيب: البصمة=100، تطابق الاسم/السنة/الحلقة/fps، عقوبة slangs والترجمات الآلية |
| `textfix.go` + `text_tables.go` | فك ZIP وإصلاح الترميز بجداول WHATWG مولّدة |
| `cache.go` | bbolt + الذاكرة الساخنة + النماذج المشتركة |
| `keypool.go` | تدوير المفاتيح والتوقف التلقائي |
| `provider_os.go` / `provider_subdl.go` | مزوّدا OpenSubtitles وSubDL |
| `*_test.go` | 31 اختباراً + قياسات أداء |

## ملاحظات

- **الترجمات الآلية من المزوّد** (`ai_translated` في OpenSubtitles) تُخفض درجتها في الترتيب لأنها غالباً رديئة — لا تُنتجها الخدمة نفسها إطلاقاً.
- دوّر فقط بين مفاتيح وحسابات تملكها فعلاً والتزم بشروط كل مزوّد؛ لا تضع المفاتيح في التطبيق أبداً.
- OpenSubtitles: البحث بمفتاح API والتنزيل يحتاج تسجيل دخول الحساب؛ عدّل `OPENSUBTITLES_DAILY_LIMIT` حسب خطتك.
- الاتصال بالتطبيق HTTPS فقط (Render يوفر TLS)، وبلا تحويلات تلقائية، وبسقف 5MB للاستجابة (جانب التطبيق).
