# خادم الترجمات الوسيط (Subtitle Aggregator)

FastAPI + SQLite. يستقبل طلبات التطبيق، ويجلب الترجمات من طبقتين، ويُصلح الترميز، ويخزّن كل شيء مؤقتاً.

## التدفق
1. `GET /search` ← تحليل اسم الملف ← كاش ← تحويل العنوان إلى معرّف TMDB/IMDb ←
2. **الطبقة 1:** Wyzie (بالمعرّفات) + OpenSubtitles (مع مجموعة مفاتيح وتدوير) ←
3. **الطبقة 2** (عند غياب ترجمة عربية): SubDL ثم كشط YIFY، ومعه Firecrawl عند حماية الموقع (اختياري) ←
4. ترتيب ذكي: العربية أولاً، بصمة الفيديو، تطابق الإصدار، التقييم والتحميلات ←
5. `GET /file/{id}` ← تنزيل + فك الأرشيف + تحويل Windows-1256/ISO-8859-6 إلى UTF-8 + كاش.

## التشغيل المحلي
```bash
pip install -r requirements.txt
cp .env.example .env   # املأ المفاتيح ثم صدّرها كمتغيرات بيئة
uvicorn app.asgi:app --port 8000
pytest -q tests        # اختبارات بلا شبكة (مزوّدون وهميون)
```

## النشر على Render (الخطة المجانية)
ارفع المجلد إلى GitHub ثم New → Blueprint (يقرأ `render.yaml`). أضف المفاتيح من لوحة Render.
`APP_TOKEN` يُولَّد تلقائياً: ضعه في التطبيق (الإعدادات ← الترجمات الإلكترونية).

تنبيه: قرص الخطة المجانية مؤقت؛ يُفقد الكاش وعدّادات المفاتيح عند إعادة التشغيل (الحدود اليومية
تُصفَّر عندئذ، فقد تتجاوز الحصة الفعلية في يوم تتكرر فيه الإعادة). للثبات اربط قرصاً دائماً وضع `DB_PATH` عليه.

## إبقاء الخادم مستيقظاً (Keep-alive)
الخطة المجانية في Render تُنيم الخدمة بعد ~15 دقيقة بلا طلبات واردة (والاستيقاظ يستغرق نحو دقيقة).
عند النشر يقرأ الخادم `RENDER_EXTERNAL_URL` (يحقنه Render) ويستدعي `/health` عبر رابطه العام كل
`KEEP_ALIVE_INTERVAL` ثانية (الافتراضي 600). محلياً يبقى معطّلاً. حالته ظاهرة في `/health` ← `keep_alive`.

حدود يجب معرفتها:
- الساعات المجانية 750 شهرياً: خدمة واحدة تعمل 24/7 تكفي (~744 ساعة)، وأي خدمة مجانية ثانية في الحساب ستستهلك من الحصة نفسها.
- لا ضمان من Render أن النبض الذاتي سيبقى فعّالاً دائماً (سياسته قد تتغير)، ولو أُعيد تشغيل الخدمة توقف النبض حتى الإقلاع التالي.
- الأوثق إضافة مراقب خارجي مجاني (UptimeRobot أو cron-job.org) يستدعي `https://<خدمتك>.onrender.com/health` كل 5–10 دقائق، ويمكن استخدامه مع النبض الذاتي أو بدلاً منه.

## الواجهة
| المسار | الغرض |
|---|---|
| `GET /search?filename=&q=&lang=ar,en&hash=&season=&episode=&imdb_id=&tmdb_id=&refresh=` | بحث مرتب. `q` للبحث اليدوي بالعنوان |
| `GET /file/{id}` | ملف نظيف UTF-8 (الصيغة في الترويسة `X-Subtitle-Format`) |
| `GET /health` | حالة المفاتيح (بلا كشفها) |

كل الطلبات (عدا `/health`) تحتاج الترويسة `X-App-Token`، وفيها تحديد معدل لكل IP (60/دقيقة).

## ملاحظات مهمة
- **المفاتيح**: دوّر فقط بين مفاتيح وحسابات تملكها فعلاً، والتزم بشروط كل مزوّد؛ إنشاء حسابات كثيرة
  للالتفاف على الحدود غالباً ممنوع. لا تضع المفاتيح في التطبيق أبداً.
- **OpenSubtitles**: البحث بمفتاح، والتنزيل يحتاج تسجيل دخول الحساب (`OPENSUBTITLES_ACCOUNTS`).
  حدّ التنزيل اليومي للحساب المجاني محدود (الافتراضي هنا 200 فعدّله حسب خطتك).
- **TMDB**: مفتاح مجاني ضروري لتحويل العنوان إلى معرّف (Wyzie لا يبحث بالعناوين). بدونه يعمل OpenSubtitles بالبحث النصي فقط.
- **الكشط (YIFY/Firecrawl)**: تجريبي ومعطّل افتراضياً (`ENABLE_SCRAPING=0`)؛ بنية الصفحات تتغير وله مخاطر شروط استخدام.
  تعامل معه كحل أخير.
- حقول رد Wyzie تُقرأ بتساهل (`url/language/format/release/...`)؛ راجع وثائقهم إن اختلفت التسمية عندك.
- لم تُجرَّب هذه المزوّدات على شبكة حقيقية هنا (الاختبارات بمزوّدين وهميين)؛ جرّب كل مزوّد بمفتاحك أولاً.
